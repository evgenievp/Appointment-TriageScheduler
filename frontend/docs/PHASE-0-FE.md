# PHASE-0-FE.md — Задание за Claude Code

Инструкции за довършване на **Фаза 0 (frontend скеле)** на проекта *Appointment & Triage Scheduler*. Работи се само в тази папка (`frontend/`). Текущ бранч: `fe-scaffold`.

---

## 1. Контекст на продукта

Система за записване на часове **за една конкретна клиника** (не multi-tenant платформа). Клиниката има няколко лекари с различни специалности и кабинети.

**Роли:** `PATIENT` (пациент) и `STAFF` (персонал/администратор на клиниката).

**Канали за записване на час** (важно за структурата на страниците):

1. **Самообслужване** — пациентът се регистрира и записва час сам през сайта.
2. **По телефона** — пациентът се обажда в клиниката; администраторът (STAFF) го регистрира и му записва час от името на клиниката. Това означава, че staff частта ще има flow „нов пациент + запис на час“, не само преглед на графика.
3. **AI асистент** — пациент казва на асистента в телефона си (напр. Gemini) да му запише час и описва оплакванията си; асистентът ползва публичното API. Това е бекенд отговорност (API/MCP) и **не се имплементира във Фаза 0**, но UI-ят не трябва да предполага, че записванията идват само от човек през браузър — всички данни идват от API-то, нищо не се пази само клиентски.

Триаж: при записване (по всеки канал) се попълва кратък въпросник за оплакванията → приоритет `URGENT` / `NORMAL`.

## 2. Текущо състояние (вече направено — НЕ го променяй, освен където е изрично казано)

- Vite + React (JavaScript, **не** TypeScript) скеле в тази папка.
- `src/main.jsx` — `QueryClientProvider` (TanStack Query) + `BrowserRouter` + импорт на `./ds/styles.css`.
- `src/App.jsx` — `<Routes>` с маршрути `/`, `/login`, `/doctors`.
- Инсталирани: `react-router-dom`, `@tanstack/react-query`.

Изисквания към имплементацията:

- `Home.html` → React компонент в `src/pages/Home.jsx` (JSX: `class` → `className`, self-closing тагове, инлайн `style` като обекти). Без TypeScript.
- CSS-ът на дизайн системата → `src/ds/styles.css` (импортът в `main.jsx` вече съществува). Никакъв инлайн/копиран CSS в компонента, освен ако е специфичен само за Home — тогава в `src/pages/Home.css`.
- `_ds_bundle.js` не се пренася като файл — ако съдържа поведение, нужно за Home (напр. мобилно меню), пренапиши го като React state/handlers.
- Линковете/CTA бутоните в Home да сочат към реалните маршрути: „Запази час“ → `/doctors`, вход → `/login`, регистрация → `/register`. Добави и видим елемент с телефона на клиниката с текст в смисъл „или се обади и ние ще те запишем“ (телефонът е placeholder, напр. `+359 2 XXX XXXX`) — това отразява канала за записване по телефона.
- Съдържанието да е за **една клиника** (име-placeholder, напр. „Клиника …“), не за платформа с много клиники.

- Не пипай нищо извън `frontend/`.
